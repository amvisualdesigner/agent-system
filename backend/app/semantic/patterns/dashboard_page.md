# pattern.dashboard_page

## Layer Type
pattern

## Hierarchy
component → pattern → layout → skill

## Purpose
Standard dashboard page composition pattern for analytics interfaces.

## Structure
1. KPI row first — summary metrics at the top
2. Charts second — timeseries and trend visualizations
3. Tables/breakdowns last — detailed data analysis

## Preferred Layout
layout.AnalyticsGrid

## Common Usage
- BI dashboard pages
- analytics primary views
- reporting home pages
