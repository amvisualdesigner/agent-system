# pattern.kpi_section

## Layer Type
pattern

## Hierarchy
component → pattern → layout → skill

## Purpose
Reusable KPI section composition pattern for metric summary rows.

## Composition
- metric cards in horizontal row
- trend indicators per card
- optional sparklines
- summary total or average

## Typical Usage
- executive summary pages
- dashboard top section
- analytics overviews
- reporting headers
