## Layer Type

## Hierarchy

## Purpose
Visual trend arrow or badge showing metric direction.

## Displays
- up/down/flat arrow
- color coding (green/red/neutral)
- optional percentage change

## Common Usage
- inside KpiCard as delta indicator
- table columns with period comparison
- metric comparison rows
- alert and anomaly indicators
