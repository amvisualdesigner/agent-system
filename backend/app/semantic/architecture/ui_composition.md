# architecture.ui_composition

## Layer Type
architecture

## Hierarchy
architecture → component → pattern → layout → skill

## Purpose
Defines how UI elements compose into analytics interfaces. Establishes the visual hierarchy and composition rules for BI dashboards.

## Composition Rules
- KPI rows sit at the top as the primary information layer
- Charts and timeseries occupy the middle visual zone
- Tables and detailed breakdowns sit at the bottom
- Filters float at the top or left edge, never in the content body
- Each section must be visually separable by spacing or containers

## Common Usage
- Dashboard page structuring
- Analytics workspace layout
- Multi-section reporting interfaces
