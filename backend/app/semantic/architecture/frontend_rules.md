# architecture.frontend_rules

## Layer Type
architecture

## Hierarchy
architecture → component → pattern → layout → skill

## Purpose
Frontend coding rules and semantic guidelines for the analytics platform.

## Rules
- Prefer reusable components over one-off implementations
- Prefer dashboard skills over raw JSX scaffolding
- Use semantic components from the component library
- Use layouts from semantic/layouts as structural containers
- Avoid inline styles; use design tokens instead
- Avoid direct fetch inside components; delegate to data contracts
- Every UI block must have a corresponding semantic descriptor

## Common Usage
- Code review standards
- Semantic planning constraints
- Component authorship guidelines
