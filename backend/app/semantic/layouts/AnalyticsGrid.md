## Layer Type
layout

## Hierarchy

## Purpose
Responsive grid-based analytics dashboard layout.

## Structure
- KPI row at top
- chart region in middle
- filter sidebar or top bar
- metrics table at bottom

## Typical Usage

- reporting portals
- operational analytics
- SaaS overview pages
