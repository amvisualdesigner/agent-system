# layout.TwoColumnDashboard

## Layer Type
layout

## Hierarchy
component → pattern → layout → skill

## Purpose
Two-column dashboard layout for side-by-side metric comparison.

## Structure
- left column: primary KPI + main chart
- right column: secondary metrics + supporting charts
- full-width filter bar at top

## Typical Usage
- A/B comparison dashboards
- campaign performance views
- side-by-side analytics
- operational monitoring
